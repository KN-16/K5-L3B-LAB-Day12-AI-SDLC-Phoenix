# Phoenix v1.0.0

## Điểm mới

- Lặn & Hái, Mở Quán và Shop nối thành vòng ngày. Có Cá Sấu Năm Chèo, sáu món, nâng cấp, pause và HUD.
- Kho lưu từng nguyên liệu cùng ID và độ tươi. Khách giữ phần hàng theo ID, bếp chốt giá theo độ tươi khi nấu.
- Có chế độ tương phản cao và ba cảnh báo bằng chữ. Manifest v1.3 có lệnh benchmark Canvas và soak headless.

## Cách chạy

Giải nén ZIP, vào thư mục chứa `game.contract.json`, chạy `python3 -m chonoi.live --mode day` rồi mở URL được in ra. Cần Python 3.12 trở lên và trình duyệt. Dùng WASD hoặc phím mũi tên để đi, E tương tác, Space bắt cá, P hoặc Esc tạm dừng và H đổi tương phản.

## Giới hạn đã biết

- File kho v1.0/v1.1 dùng số lượng theo loại. Dùng tag `phase-2` để chạy các fixture kho đếm.

- Game chạy qua máy chủ cục bộ. Xem README về cách chạy hai ca riêng, test và xuất bằng chứng.
